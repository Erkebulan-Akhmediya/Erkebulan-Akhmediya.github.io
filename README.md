# Олимп-5 🐆

Игровой тренажёр для подготовки ученика 5 класса к городской олимпиаде по математике.
Сайт открывается с телефона: **https://erkebulan-akhmediya.github.io/**

## Что внутри

Подготовка рассчитана на **5 часов**, разбита на 5 занятий по 1 часу:

| Занятие | Что проходим |
|---|---|
| 1 | 🧮 Хитрый счёт · 🧠 Логика · ☯️ Чётность |
| 2 | 🔢 Цифры и ребусы · 🚂 Текстовые задачи · 🎲 Комбинаторика |
| 3 | 🐇 Принцип Дирихле · ➗ Делимость и остатки · 📐 Геометрия |
| 4 | 🧩 Смекалка · 🔁 Работа над ошибками · ⚡ Блиц |
| 5 | 🏆 Пробная олимпиада (60 минут, 6 задач, диплом) |

На каждом острове есть шпаргалка с разобранным примером и 6 задач с подсказками и решениями.

Игровые элементы:
- очки ⚡ и звания, от «Новичка» до «Гроссмейстера»;
- звёзды за острова;
- серии правильных ответов 🔥;
- 14 наград;
- блиц на устный счёт с рекордом;
- диплом после пробной олимпиады.

Прогресс сохраняется в браузере на устройстве. Время подготовки считается автоматически.

После первого открытия сайт работает и без интернета. Его можно добавить на главный экран телефона:
в меню браузера выберите «Добавить на главный экран».

## Откуда задачи

Официальные задания городской олимпиады Павлодара за прошлые годы в открытом доступе не опубликованы. Поэтому в тренажёре **тренировочные задачи того же типа**, что встречаются на городских и областных олимпиадах для 5–6 классов в Казахстане. Это не задания с реальных туров. Все ответы проверены программой.

## Как добавить свои задачи

Все задачи лежат в `js/data.js`. Задача добавляется в массив `problems` нужного острова:

```js
{ d: 2, type: "num", text: "Условие задачи", answer: 42,
  hints: ["Подсказка 1", "Подсказка 2"],
  solution: "Решение" }
```

Для задачи с вариантами ответа укажите `type: "choice"`, `options: ["Да", "Нет"]`, `answer: 1`. В `answer` пишется номер правильного варианта, отсчёт с нуля.

После изменения файлов увеличьте версию `CACHE` в `sw.js` и параметр `?v=` в `index.html`, иначе телефоны продолжат показывать старую сохранённую копию.

## Структура

- `index.html` — страница
- `css/style.css` — оформление (сначала для телефона)
- `js/data.js` — задачи, шпаргалки, пробная олимпиада
- `js/app.js` — логика игры
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и иконка приложения
